The four baseline failures all passed with the backport:
* cs_imgload_tfe and cs_imgload_d16_tfe (status after a resident image load)
* cs_w32_exec_computed (lane selection for computed EXEC writes)
* ms_wave_info_s3 (a mesh allocation sent by wave 1)

The baseline native mesh draw left all 4096 pixels at the clear value (-1,-1,-1,-1).
The patched native and emulated draws returned the expected gradient. Three
additional native draws per revision, alternating baseline and patched modules,
reproduced the all-clear baseline and exact patched result every time. Every
RGBA32F component matched the expected float32 value for its pixel.

The patched wave32 compute output was 259 1028 3088 7682 512 4100 0 3.
With software wave64 emulation, cs_w64_exec_computed produced
291 1028 11264 771 8192 4132 0 3. The device cannot run native 64-wide subgroups.

Five native CTests passed: depth24_convert, vk_command_replay,
vk_overlapping_occlusion, vk_overlapping_occlusion_no_statistics and
vk_bc_zero_init. A control draw with the repository's vs_tri.vert and fs_solid.frag
returned the expected color at all 4096 pixels.

Reproduce each full run in a fresh --work directory:
  python -I scripts/run_gpu_tests.py --require-pass --build <native-build> --work <fresh-directory>
For the emulated run, set LEONIDA_W64_EMULATE=1. The hardware tests used a
25-second per-program timeout. The accompanying patch applies with git apply at
the base SHA above. No retail game, Windows D3D12 layer or presenter was tested.
